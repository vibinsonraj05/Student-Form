# 🎓 Student Registration Form

A modern, responsive, multi-step student registration form inspired by Google Forms. It provides a clean interface for collecting student information through a simple step-by-step registration process.

## ✨ Features

- **Multi-Step Registration** – Complete registration across three steps.
- **Student Details** – Collect personal and academic information.
- **Contact Information** – Enter mobile number, email, and address.
- **Course Selection** – Select the preferred course and department.
- **Profile Photo Upload** – Upload a student photo.
- **Form Validation** – Validate required fields before proceeding.
- **Progress Indicator** – Track registration progress.
- **Navigation Controls** – Move between steps using Next and Back buttons.
- **Responsive Design** – Works across desktop, tablet, and mobile screens.
- **Success Screen** – Displays confirmation after completing the form.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/vibinsonraj05/Student-Registration-Form.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Student-Registration-Form
   ```

3. Open `index.html` in your browser.

## 📸 How It Works

1. Enter student details in Step 1.
2. Provide contact and course information in Step 2.
3. Complete the final details in Step 3.
4. Review the information and submit the form.
5. View the registration success screen.

## ⚠️ Note

This is a frontend demonstration project. Form submissions are handled on the client side; no backend database or permanent registration storage is connected.
